# Second brain contatti

Personal-use application. It reads the Google Contacts of its owner (read-only, scope `contacts.readonly`) to produce an export on the owner's private home server. It is not offered to other users and has no public service.

App personale. Legge i contatti Google del solo titolare, in sola lettura, per produrre un'esportazione sul suo server privato. Non è destinata ad altri utenti.
